# פתח בוואטסאפ

אתר קטן שמקבל מספר טלפון בכל פורמט, למשל `052-123-4567`, `+972 52…`, `00972…`, `(212) 555-1234` או `07400 123456`. הוא מזהה את המדינה, מסדר את המספר ופותח שיחת וואטסאפ בלי לשמור איש קשר.

- אחרי הביקור הראשון האתר עובד גם בלי אינטרנט (service worker).
- אפשר להוסיף אותו למסך הבית כאפליקציה. באנדרואיד הוא מופיע גם בתפריט "שתף".
- קישור עם מספר מוכן: `…/?n=0521234567`

## קבצים
- `index.html`: כל האתר.
- `sw.js`: שמירה במכשיר לעבודה בלי רשת.
- `manifest.webmanifest` וקובצי `icon-*`: התקנה כאפליקציה.

## הרצה מקומית
```
python -m http.server 8765
```
ואז לפתוח http://localhost:8765

## עדכון גרסה
אחרי כל שינוי צריך להעלות את `VERSION` בקובץ `sw.js` (למשל ל-`wa-open-v2`), כדי שהמכשירים יורידו את הגרסה החדשה.
